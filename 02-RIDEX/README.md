# RIDEX – Ride Booking and Driver Matching System

RIDEX is a C++-based ride booking project designed to demonstrate how core
data structures, algorithms, and object-oriented programming concepts can
be applied to a real-world ride-booking workflow.

## Key Features

- Ride booking and driver assignment
- Driver matching logic
- Object-oriented system design
- Use of data structures for managing drivers and bookings
- Graph-based shortest-path concepts
- JSON-based input and output (if implemented in the project)

## Technologies Used

- C++
- Object-Oriented Programming
- Data Structures and Algorithms
- Graph Algorithms
- JSON (if used in the implementation)

## Core Concepts

| Concept | Purpose |
|---|---|
| OOP | Organizes the system into reusable classes |
| Strategy Design Pattern | Supports interchangeable matching strategies, if implemented |
| Priority Queue | Helps manage priority-based selection |
| Unordered Map | Supports efficient key-based lookup |
| Dijkstra's Algorithm | Finds shortest paths in a weighted graph, if used |
